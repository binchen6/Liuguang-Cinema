# 流光影院 1.3.1

## 搜索、详情与来源恢复

- 投屏“手机扫码”改为标准居中对话框，窄窗也完整显示二维码、链接和复制操作。
- 左侧导航默认收窄到 196 DIP，按文字实际测量结果扩展，不截断超长本地化文本。
- 搜索加入防抖自动补全，支持中文 IME、键盘选择、轻点外部关闭；历史回填和程序化赋值不触发远程建议，正式提交会取消待处理建议。
- 详情页支持集数搜索和跨站查找换源；片源与线路同排显示，封面按窗口高度自适应，低高度窗口也能操作来源。
- 播放失效先刷新媒体地址，再提供已检索到的候选来源；历史记录可自动换源，失败保留原记录。切换按集名优先、集数次选恢复，并保留播放位置。

## 播放器与稳定性

- LibVLC 停播、重建、轨道读取和进度读取由后台串行执行，界面只消费状态快照，避免原生等待卡住窗口线程。
- 修复异步交换链初始化的生命周期竞争、UI 线程限定对象跨线程访问，以及窗口关闭时未先卸载页面视觉树导致的 XAML 原生崩溃。
- 增加缓冲状态、播放进度看门狗和预缓存后自动续播；连续缓冲时可增加缓存并降低普通画质，手动原画不自动降档，自动画质可在设置中关闭。
- 新增逐集片头片尾：手动输入秒数或使用当前位置，自动跳过片头、到片尾进入下一集；数据按站点、影片、线路和集数隔离。
- 顶部标题、进度条和底部操作统一在 5 秒无操作后隐藏，同时隐藏视频区域鼠标；菜单和对话框打开时保持可操作。
- 底部只保留高频操作，音轨、字幕、在线匹配和画中画收进顶部“播放选项”。

## 弹幕、字幕、下载与本地媒体

- 弹幕来源可独立切换“来源自带/本地文件”和“哔哩哔哩在线匹配”，支持换集自动匹配与手动重新匹配。
- 在线匹配同时覆盖 B 站 `media_ft` 与 `media_bangumi`，精确匹配标题和集数；在线字幕可转换为 WebVTT 并缓存。
- 下载面板支持多选、全选、默认目录批量下载和单集另存；同名文件自动分配新文件名，单集失败不丢弃其它成功项。
- 媒体库新增本地视频：多文件导入、文件夹递归索引、事件防抖与定期兜底更新；移除索引或停止监视不删除原文件。
- 支持同名本地字幕和弹幕。安装器注册常见视频格式的“打开方式”候选，不修改系统默认播放器。
- 文件参数直达播放跳过站点配置、Java 爬虫、直播和网盘代理初始化；完整应用已运行时复用现有窗口。

## 存储维护

- 设置页提供分类扫描与高级清理，显示估算大小和实际释放结果。
- 应用缓存、在线字幕、投屏临时文件、未完成下载、已下载媒体、过期用户临时文件和回收站分别处理。
- 已下载媒体、临时目录和回收站必须单独勾选并二次确认；被占用、无权限、重解析点和近期文件跳过。
- HLS 下载清理只删除清单实际引用的分片，不删除同目录中其它下载或本地媒体。

## 边界

- 弱网策略经过协议和故障夹具验证，不代表所有真实网络、GPU、站点或 CDN 都能持续无卡顿。
- 第三方站点、网盘账号权限、地区限制和在线字幕可用性由原服务决定。本轮没有重新扫码的账号不列为真实账号验收。
- 安装包未购买 Authenticode 签名，可能显示 SmartScreen；发布时提供 SHA-256。
- 原创代码与第三方代码许可不同，详见根目录 `LICENSE` 和 `THIRD_PARTY.md`。
