# 流光影院 1.9.6

## 播放与云盘

- UC 网盘原画接口返回拒绝、会员或浏览器提示时，播放器会逐档尝试账号可用的转码，显示实际播放画质。转码缺失时，自动画质可以使用账号已有的原画。资源仍受限时，播放请求会提示检查 UC 官方客户端或选择可用线路。原画下载会拦截识别出的提示视频。
- 厂长适配新版页面。客户端通过 WebView2 加载目录、详情与选集，从原站公开播放器读取可用媒体。在 Windows 客户端实测第二条 1080P 线路持续播放。线路未提供媒体时，播放页会提示切换线路或检查原站。
- 云盘搜索分页沿用已提交的搜索词，切换账号或搜索后，过期请求不会覆盖新页面的登录状态。

## 安全与稳定性

- 更新摘要来自 GitHub 官方发布元数据或官方 SHA-256 文件。镜像仍可加速安装包传输。增量安装前校验目标版本，避免将补丁应用到不匹配的安装目录。
- 跨域重定向过滤 Cookie、Authorization 等请求信息。CatVod 恢复系统证书校验，媒体代理校验回环请求，并限制连接数和请求头大小。
- 升级 AngleSharp、OkHttp、Gson、jsoup、Commons Lang 和 JSON-java。默认签名服务托管原有弹弹play AppId 和主备 AppSecret。新安装可以直接获取弹幕。设置中可填写自定义凭据，AppSecret 使用当前 Windows 用户的 DPAPI 加密保存。

## 下载

- `TV-Setup-1.9.6-x64.exe` 为完整安装包。
- `TV-1.9.6-win-x64-portable.zip` 为便携包。
- `TV-Update-1.9.6-from-1.9.5-x64.exe` 用于从 1.9.5 增量升级。

所有包均附有 `.sha256` 文件。
