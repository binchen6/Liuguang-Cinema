# 流光影院 1.9.0 发行说明

发布日期：2026-11-23

## 核心更新

### 1. 全新品牌设计语言：「白 · 隙 · 镜」（SHIRO · MA · GLASS）
- 参考**原研哉（Kenya Hara）的「白与余白」哲学**，融合**国际现代平面设计排版秩序**与**建筑级磨砂玻璃（WinUI `AcrylicBrush` + `1px` 高光描边）**，建立全新的完整品牌规范与动效规范文档（`docs/brand-design-system.md`、`docs/motion-spec.md`、`docs/design-guide.md`）。
- **暗室素墨（默认深色）与素白画廊（浅色）双主题体系**：全面告别旧版深蓝灰与暖黄配色，以温润素墨黑（`#0B0B0D`）与宣纸白（`#F6F5F0`）作为静谧银幕画布，主操作采用克制的**墨白高反差**，并以单一**朱砂落款红（Vermilion `#E8503E` / `#CE3A2B`）**点缀品牌光点、滑轨指示条、进度光束与 `ON AIR` 广播状态；完整支持 Windows 高对比度无障碍模式。

### 2. 「光隙 · Aperture」品牌图标与全站几何图标翻新
- 全新设计并重新生成 512×512 高清应用主图 `App.png` 与内置 `16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256` 九档无损位图的 `App.ico`（68 KB），以素墨暗室单体、内层磨砂玻璃框、光隙棱镜与朱砂红点塑造高辨识度品牌标识。
- 新增应用内纯矢量组件 `BrandMark` 与 24×24 统一 1.65px 线宽建筑几何线框图标库（`Styles/Icons.xaml` + `LineIcon`），覆盖侧栏、各页面工具栏、设置分区与播放器控制栏，任意 DPI 下像素级锐利显示且自动跟随主题与交互状态变色。

### 3. 全软件界面深度重构
- **应用主壳与侧栏**：升级为磨砂透光导轨，配备纯矢量「光隙」标识、键帽式全局搜索入口（`Ctrl F`）、带画册索引编号（`01`–`06`）的定制图标导航与弹性朱砂滑轨。
- **点播页**：重构为画册报头 + 展厅磨砂铭牌宽幅画廊 + 滚动自动切换的悬浮磨砂玻璃筛选坞 + 双层景深画框海报（悬停内图独立微缩放 + 磨砂圆镜播放徽章）+ 磨砂圆形回顶键。
- **详情页**：全出血柔光磨砂画报区（120fps GPU 滚动视差底纹 + 朱砂垂直简介引线）+ 非对称磨砂双栏工作台（片源检视器与编号选集矩阵）+ 画册相关推荐。
- **搜索页**：一体化磨砂命令搜索条（底部内嵌 2px 朱砂进度光束）+ 真磨砂非抢焦搜索建议浮层 + 左侧磨砂站点遥测轨 + 统一画框结果网格。
- **直播 / 媒体库 / 我的云盘 / 投屏 / 设置**：
  - 直播页新增朱砂 `ON AIR` 呼吸灯与磨砂节目单检视面板；
  - 媒体库升级为磨砂分段滑轨（弹性玻璃胶囊水平滑行）与 3px 朱砂进度条继续观看卡；
  - 我的云盘整合磨砂账号卡与一体化路径搜索带；
  - 投屏页升级为磨砂遥测控制台与同心光学雷达波纹待机舞台；
  - 设置页升级为带弹簧滑轨指示条的磨砂分区导航与全新「光隙」品牌关于画报页。
- **播放器与弹窗**：升级为悬浮式烟熏磨砂玻璃底部控制坞、磨砂圆镜中央播放键、等宽数字时间码，以及统一样式的烟熏磨砂 OSD、AI 字幕浮条、媒体信息 HUD 与更新/登录弹窗。

### 4. GPU Compositor 顶级可打断物理动效引擎
- 全面升级 `MotionService`，全链路运行在 WinUI Compositor 线程并保持动量守恒、随时可打断与严格无障碍降级（`MotionService.CanAnimate`）：
  - 页面方向性空间转场（`EnterPage`）与 GPU 延迟错峰画册级联（`StaggerEntrance`）；
  - 侧栏、设置分区与媒体库分段滑轨的**位移比例弹性拉伸滑行**（`GlideVerticalIndicator` / `GlideHorizontalPill`）；
  - 卡片悬停双层景深微缩放与虚拟化容器复用自动复位（`ResetCard`），杜绝快速滚动残留缩放态；
  - 全站高频按钮、下拉选择器（`AnchoredChoice`）与播放器空格键脉冲的触感反馈（`AttachTactile` / `PulseElement`）；
  - 顶部锚点磨砂浮层弹性展开、连按不闪烁微弹 OSD、GPU 滚动视差表达式、LIVE/投屏呼吸光点与雷达波纹。

### 5. 全面实机 Debug 与边界修复
- 修复运行时动态切换深色/浅色/高对比主题时，点播吸顶筛选坞、设置按钮底板与侧栏历史项可能残留旧画刷或双指示条的问题。
- 修复站点未就绪时点播标题旁站点胶囊显示空圆框、媒体库首帧分段滑轨胶囊未落位、关于页品牌画报在中等宽度下折行裁切等实机细节问题。
- 为高对比度主题补齐深色铭牌前景色语义键，高对比模式下自动隐藏背景装饰光晕。
