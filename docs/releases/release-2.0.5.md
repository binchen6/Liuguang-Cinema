# 流光影院 2.0.5

本版包含自 1.9.8 以来各次大版本（2.0.0 · 2.0.1 · 2.0.3）的主要更新汇总与本版（2.0.5）的全部新增能力。

## 2.0.5 新增：弹幕体系重构

- 弹幕来源升级为三类（弹弹play 开放弹幕库、哔哩哔哩、其他聚合）加智能匹配与来源自带/本地文件共五种模式，开启弹幕后默认按「哔哩哔哩 → 其他聚合 → 弹弹play」的顺序智能匹配，当前类别无匹配时自动尝试下一类。
- 「其他聚合」为参考 Danmaku-Anywhere/dango（dango-manifests）契约的 C# 原生实现：新增爱壹帆（yfsp.tv）与人人视频两个聚合源，含站方签名口径还原（爱壹帆 pConfig 公私钥 + MD5 vv 校验、人人 MD5 参数签名），按标题评分选剧并按集号/集名挑选分集。
- 播放器弹幕设置弹层按新来源体系重构：五类来源选择、智能匹配顺序实时提示；「设置 → 弹幕与 AI」新增匹配顺序调整（六种全排列预设，即时保存即时生效）。

## 2.0.5 修复与体验

- 修复片头片尾设置弹窗内输入框因固定高度被裁剪导致数值不可见的问题（弹幕时间轴、字幕偏移同样受益）。
- 片头片尾记忆从「站点 + 线路 + 单集」升级为按节目生效：同一节目跨集数、跨站点共用同一套片头片尾设置。
- 修复「The operation was canceled.」英文原文透出：所有内置 HTTP 请求的内部超时统一转译为友好的中文超时提示，站点验证弹层不再因此显得无法关闭。
- 点播页仓库切换按钮支持右键「刷新当前仓库」，无需切换仓库即可重新拉取最新配置。
- 仓库支持备用地址：主地址刷新失败时自动改用备用地址拉取并提示；设置页仓库列表新增「备用地址」编辑入口，默认显示 3 个仓库、其余折叠为「查看更多」。
- 点播页筛选增强：年份改为下拉选择、排序新增评分维度、筛选按钮显示生效条件数、支持一键「重置筛选」。
- 修复本地回环媒体代理接受循环可能因单连接异常终止的问题（表现为直播源 127.0.0.1 主动拒绝，如摸鱼直播源 superiptv）；满载时改为背压等待而非直接断开。
- 修复磁力会话异步释放丢弃 ValueTask 的隐患，修复字幕时间轴等待 Win32 事件失效时的空转。

## 2.0.5 修复：四盘系站点

- 「聚剧┃四盘」（seedhub）的 Cloudflare 盾站验证链路与「盘搜┃四盘」失效端点的错误提示已修复，盘搜端点全部不可达时给出刷新仓库或改用易搜/聚剧的明确指引。

## 2.0.5 新增：.so 原生库站点通用兼容

- 依赖闭源 Android ARM 原生库（如 FishGuard 系防护）的站点，桌面端无法直接加载 .so；现按影视仓/OK影视的通用做法，自动尝试站方标准 MacCMS JSON 接口（`api.php/provide/vod` 端点族）恢复目录、搜索、详情能力，并在设置 → 片源声明 `desktopApi` 或仓库适配包时优先走对应通道。

## 自 1.9.8 以来的主要更新汇总

- **音乐播放（2.0.1）**：音频自动进入音乐播放器，封面、曲目信息与逐句歌词同步；在线匹配封面与歌词；进程音频回环驱动节拍光效；双语滚词与歌词翻译；本机歌词复用。
- **弹幕屏蔽（2.0.0）**：逐行 .NET 正则屏蔽、基础广告规则、后台筛选与即时清屏。
- **视觉与材质（2.0.1/2.0.3）**：深色月光 + 透光玻璃、浅色日光 + 磨砂玻璃双主题体系；五层玻璃表面、GPU 光学引擎与统一导航样式；修复全屏白条、控件对齐与悬停高光收起等细节。
- **仓库与站点适配（2.0.0-2.0.3）**：仓库资源包管理（清单校验、SHA-256、国内加速、ZIP 导入、热重载）；通用协议、HTML、drpy2 JS 与 Python 片源；饭太硬旧配置迁移；摸鱼仓库专属页面；`desktopApi` 桌面兼容接口；磁力链接播放与下载。
- **播放内核（2.0.0-2.0.3）**：无回弹拖拽、逐帧进度、画中画、防休眠、M3U8 净化、跨版本全量与增量更新加固（清单校验、便携原地覆盖、失败自愈回退全量）。
- **安全与工程（2.0.0-2.0.3）**：DPAPI 凭据加密、日志脱敏、外部适配器默认关闭、Bouncy Castle 1.87、零明文凭据入仓与 84+ 项离线协议回归。
