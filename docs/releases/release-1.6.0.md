# 流光影院 1.6.0 发布说明

发布日期：2026-11-22

## 本次更新

### 1. 全站 UX / UI 深度重构
- **影院级深墨暖金视觉体系**：升级 `Tokens.xaml` 与 `Controls.xaml`，深化暗色层次与高对比度描边，全面修复输入框/密码框占位符偏上、Disabled 主按钮低对比度以及侧栏列表文字与指示条碰撞问题。
- **点播与详情页重构**：修复详情页元数据标签因 `ItemsWrapGrid` 统一列宽导致的严重截断问题（新增自适应 `WrapPanel`）；引入海报环境氛围光晕英雄卡、带图标操作栏与分层卡片式选集/线路区；收紧点播首屏留白与精选画廊高度，消除无年份卡片的孤立圆点 `·`。
- **全局导航与页面精细化**：修复左上角品牌图标裁切偏移与投屏页残留返回键问题；替换全部投屏图标为规范 Cast 图标；修复直播频道台标 `UniformToFill` 裁切（改为 `Uniform` 完整呈现）；设置页全面升级为全宽分组卡片布局，媒体库胶囊标签增加呼吸内边距。

### 2. WinUI Composition 物理动效引擎（可随时打断）
- **完全重写 `MotionService`**：彻底移除僵硬的线性 `InsetClip` 揭示与不可打断的 XAML `Storyboard`，改用合成线程 GPU 驱动的 `SpringVector3NaturalMotionAnimation` 与电影级贝塞尔曲线。
- **全应用动效编排**：
  - 侧栏新增全局弹簧滑行指示条，在点播/直播/媒体库/投屏/设置间丝滑惯性滑移；
  - 页面切换改为按导航层级区分的 `TopLevel / DrillIn / DrillOut / Immersive` 物理转场，高频连点 10 次 100ms 切页实测零卡顿、零残留；
  - 点播/搜索/相关推荐海报卡片全面升级为弹簧抬升 + 播放徽章弹入 + 按压回弹；
  - 播放器顶底控制栏、OSD 气泡、中央播放键及回到顶部按钮均支持中途随时反向打断平滑过渡；
  - 严格遵守应用内动效开关与 Windows 系统无障碍动画设置。

### 3. 全站原生还原与回归核验
- **豆瓣片单 (`点我切源`)**：全新原生 `DoubanVodProvider`，还原 7 类实时榜单、筛选与分页，补全豆瓣主体详情与官方高清预告直链（实测后台解码 227 视频帧）。
- **荐影预告片 (`YGP`)**：全新原生 `YgpVodProvider`，还原院线热映/即将上映/最受期待片单与高清 MP4 预告直链（实测后台解码 217 视频帧）。
- **新6V (`新6V`)**：全新原生 `Xb6vVodProvider`，动态发现 `/e/search/so.php` 修复全部 5 组关键词搜索与分页崩溃，完整提取详情与磁力直链。
- **体育直播与回放 (`alllive` / `吃瓜` / `多多`)**：统一接入 HTTPS `KanqiuVodProvider`（23 分类、55 场直播、1442 页高清录像回放、14 线路解析），`多多` 首页直达热门体育回放。
- **多盘搜索 (`YpanSo` / `抠搜` / `UC` / `JPan` / `BpanSo`)**：新增原生 `PanSearchVodProvider`（共享缓存 + 速率节流 + 自动回退 `panso.vip` 避免 429），并修复未登录/失效分享导致的详情 `InvalidDataException` / 404 报错。
- **立播 (`立播`) 与推送/占位项 (`push_agent` / `cc`)**：新增 `LibvioVodProvider` 接入浏览器验证交互弹窗；新增 `PushVodProvider` 优雅处理直推链接与空配置提示项。
- **全量回归**：已适配的玩偶哥哥、厂长、奥特、比特、Dm84、Bili、看球、Aid、兔小贝、虎牙js、斗鱼js 及全部 5 个直播源回归巡检全部通过。
