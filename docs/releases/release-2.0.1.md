# 流光影院 2.0.1

## 音乐播放

- 音频文件和站点音轨自动打开音乐播放器。封面、曲目信息和逐句歌词与播放进度同步，点击有时间戳的歌词可跳转。媒体库的本地媒体页可以按视频和音乐筛选。
- 封面与歌词可来自音频文件、同名文件或站点，也可以手动导入。播放器提供按曲名和歌手在线匹配的入口。
- 支持进程音频回环的 Windows 上，播放器背景随低频节拍变化。歌词跟随与玻璃动效响应系统动画设置。
- 音乐和视频的控制坞改用清透玻璃材质，保留内倒角和边缘高光。

## 仓库适配与兼容性

- 通用适配保留子目录、端口和固定查询参数，自动识别 CMS 接口、HTML 搜索表单和实际分页链接。不同仓库即使使用相同站点标识，也会独立探测和缓存。
- 摸鱼仓库的设置中心、文件浏览、网盘市场和推送接收有对应的页面入口。音乐站点可使用来源提供的独立音轨。通用站点遇到 412 可尝试配置中的备用接口，哔哩哔哩的媒体线路可使用接口返回的备用地址。
- 资源包清单支持备用 GitHub 官方端点，请求失败时可复用本地缓存。设置 → 片源 → 仓库资源包支持从本地导入 ZIP。
- Windows 安装包和便携包附带 Python 3 嵌入版、Java 17 及微软签名的 WebView2 在线引导程序。缺少 WebView2 时可联网按需安装。
- 隐藏的播放解析窗口移出界面布局，修复左侧导航栏中央的黑点。

## Windows x64 下载

- `TV-Setup-2.0.1-x64.exe` · 完整安装包。
- `TV-2.0.1-win-x64-portable.zip` · 便携包。
- `TV-Update-2.0.1-from-2.0.0-x64.exe` · 从 2.0.0 升级的增量包。

每个包附带 SHA-256 校验文件。Windows 10 1809 及以上支持安装与播放，节拍响应取决于系统和音频设备是否支持进程回环。上游账号、站点验证与链接可用性随来源变化。
