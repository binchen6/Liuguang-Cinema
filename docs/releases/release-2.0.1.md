# 流光影院 2.0.1

## 音乐播放

- 音频文件和站点音轨自动打开音乐播放器。封面、曲目信息和逐句歌词与播放进度同步，点击有时间戳的歌词可跳转。媒体库的本地媒体页可以按视频和音乐筛选。
- 封面与歌词可来自音频文件、同名文件或站点，也可以手动导入。播放器提供按曲名和歌手在线匹配的入口。
- 支持进程音频回环的 Windows 上，播放器背景随低频节拍变化。歌词跟随与玻璃动效响应系统动画设置。
- 音乐和视频的控制坞使用清透玻璃材质，保留内倒角和边缘高光，独立于深浅主题切换。音乐播放器采用五层不规则日光与焦散折射光场，低频节拍与封面、顶栏和控制坞的漫反射与菲涅尔边光实时联动，当前歌词呈现柔和玻璃光晕。
- 深色主题采用月光 + 透光玻璃体系，浅色主题采用日光 + 磨砂玻璃体系，全局玻璃控件、下拉按钮、导航项与滑块统一接入光学折射与几何居中校准，修复播放键三角偏心、滑块轨道错位及相邻控件高度不一致问题。

## 仓库适配与兼容性

- 通用适配保留子目录、端口和固定查询参数，自动识别 CMS 接口、HTML 搜索表单和实际分页链接。不同仓库即使使用相同站点标识，也会独立探测和缓存。
- 摸鱼仓库的设置中心、文件浏览、网盘市场和推送接收有对应的页面入口。音乐站点可使用来源提供的独立音轨。通用站点遇到 412 可尝试配置中的备用接口，哔哩哔哩的媒体线路可使用接口返回的备用地址。
- 资源包清单支持备用 GitHub 官方端点。两个地址均不可达时，客户端使用本地缓存或随包清单。首次离线启动也能安装随包的摸鱼适配包。设置 → 片源 → 仓库资源包支持从本地导入 ZIP。
- Windows 安装包附带 Python 3 嵌入版、Java 17 及微软签名的 WebView2 在线引导程序。缺少 WebView2 时可联网按需安装。Java 运行时会处理当前 Windows 代码页无法表示的安装路径。
- 深度加固跨版本与增量更新链路：发布包内置 `install-manifest.txt` 文件清单，完整安装包覆盖升级前自动清理旧版运行时与已移除残留文件，并在静默全量升级结束后自动重启进入新版本；后续增量更新在客户端下载前强制校验本地安装清单与核心文件哈希，若检测到文件缺失、跨版本跳跃或上次增量未完成则自动切换全量包自愈；修复网页回退源下的近似文件大小校验误报。
- 隐藏的播放解析窗口移出界面布局，修复左侧导航栏中央的黑点。

## Windows x64 下载
