# 流光影院 1.4.0

本版本在 1.3.1 的搜索、换源、播放器、网盘、弹幕、批量下载、本地媒体和高级清理功能之上，完成性能与稳定性收尾。完整功能说明见[1.3.1 版本说明](release-1.3.1.md)。

## 播放与预读

- Range 预读按实际分块耗时调整窗口：慢分块降低并发，连续慢响应缩小后续分块；连续快速响应在原设置上限内逐步恢复。
- 保持严格 Content-Range、文件长度和 ETag/If-Range 校验，不用降低完整性换取速度。
- 已验证完整字节重组、有界客户端 Range、初始地址刷新、后续分块 412 刷新、HLS 双音轨与字幕、LibVLC 解码和停止。
- 播放器后台状态快照、逐集片头片尾、缓冲提示、5 秒统一控制层显隐和失效来源恢复沿用 1.3.1 的稳定实现。

## 清理与维护

- 在线字幕缓存清理同时覆盖下载失败留下的 `.vtt.tmp`，仍限制在应用自己的字幕缓存目录。
- 高级清理继续要求已下载媒体、过期临时目录和回收站单独勾选并二次确认。
- 发布工作区已清理历史安装副本、过期测试 profile、旧运行库、截图和日志；保留正式安装器归档、离线构建依赖、测试源码与当前验收结果。
- GitHub 源码、README、第三方来源和许可证说明已整理；公开源码树与本地发布提交逐文件一致。

## 安装与边界

- 安装包输出到 `artifacts/installers`，提供独立 SHA-256；GitHub Release 使用同一文件。
- 安装器未购买 Authenticode 签名，可能显示 SmartScreen。
- 预读和缓冲策略不能承诺所有真实网络、GPU、地区、第三方站或 CDN 都无卡顿。未重新扫码的账号不列为本轮真实账号验收。
- 第三方代码和在线服务适用各自许可与条款，详见 `THIRD_PARTY.md`。
