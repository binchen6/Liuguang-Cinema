# 流光影院 1.4.1

本版本对播放器、页面状态、网络传输、本地媒体和存储维护进行系统人工审查，集中修复生命周期竞态、资源泄漏、跨域凭据作用域和长期运行开销。

## 播放与网络

- 播放加载、停止和离页统一使用操作代次，取消或过期任务不能覆盖最后一次用户操作；LibVLC 后台命令按顺序执行。
- 修复主媒体、音轨和动态网盘字幕代理地址的释放，取消解析或恢复时也会回收临时媒体资源。
- 预读读取被取消后保留并复用正在下载的分块，避免重复请求；代理增加请求头、响应体和传输空闲超时，并使用共享缓冲区。
- Java 启动探测移出 UI 线程并限制进程等待时间；忽略爬虫标准输出中的非 JSON 日志，避免无关日志重启整个运行时。

## 界面与交互

- 详情页主操作保持同高同宽，封面、简介、来源和选集支持窄窗纵向重排，元数据可自动换行。
- 批量下载固定开始时的详情、线路和集数快照；“取消下载”同时覆盖单集与批量任务，下载弹层按主次操作重新分组。
- 媒体库页头支持窄窗布局，成功和失败反馈分开显示；本地目录自动更新可靠切回 UI 线程。
- 设置页避免重复加载，连续修改合并后异步保存，退出前确保落盘；播放器保存实际音量并恢复静音前音量。

## 性能、存储与安全

- 海报列表只读取本地元数据缓存，打开详情时再联网补全；图片按目标尺寸直接解码，并以数量和总像素共同限制内存缓存。
- EPG 相同地址合并下载，缓存锁不再覆盖网络请求，XML 改为流式读取；诊断日志增加单份大小上限和一份轮转备份。
- 数据库写操作统一串行化并设置有界 busy timeout；清理扫描达到数量上限后立即停止，HLS 资源清理同时移除空目录。
- HLS 下载及重定向按目标站点限制 Cookie、Authorization 等敏感请求头；CMS XML 禁止 DTD，播放解析结果仅接受有效 HTTP/HTTPS 地址。
- 本地视频支持大写侧车扩展名和本地 XML/JSON 弹幕；移除文件或监视目录前统一规范化 Windows 路径。

## 安装与边界

- 安装包输出到 `artifacts/installers`，GitHub Release 使用同一文件和独立 SHA-256。
- 安装器未购买 Authenticode 签名，Windows 可能显示 SmartScreen。
- 未重新扫码的真实网盘账号不列为本轮账号验收；第三方站点、CDN、GPU 和地区网络差异仍可能影响实际体验。
- 第三方代码和在线服务适用各自许可与条款，详见 `THIRD_PARTY.md`。
