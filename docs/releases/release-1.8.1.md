# 流光影院 1.8.1 发行说明

发布日期：2026-11-23

## 封面显示与加载性能

- 修复图片解码完成后在后台线程读取 `BitmapImage.PixelWidth/PixelHeight` 导致的 UI 线程亲和性 `COMException`，该异常会让 JPG、PNG、WebP 等封面整页无法显示。
- WinRT 流创建、WIC 解码和像素统计统一在正确的 UI 调度上下文执行；网络、磁盘读取和特殊格式转码仍在后台完成。
- 限制同时进行的 WIC 解码与后台磁盘规范化任务，减少首屏大量封面造成的 UI 排队和 CPU 争用。
- 失败卡片不再永久缓存一个已完成但为空的视觉任务，后续进入视口时可以重试；封面绑定异常会写入脱敏诊断日志。
- 保留首屏预取、短时负缓存、有界内存 LRU 和后台磁盘缓存；断网重启可直接使用有效缓存。

## GitHub 更新与自动安装

- 「设置 → 关于」新增软件更新区域：手动检查、默认开启的自动检查、当前状态和更新入口。
- 自动检查读取固定仓库的 GitHub 最新正式 Release，每 12 小时最多一次；播放中不弹出，离开播放页后再提示。
- 更新弹窗与现有暖金/圆角视觉统一，展示版本变化、发行说明、补丁或完整包类型、大小和下载进度。
- 用户明确点击「下载安装」后才下载；支持取消、失败重试和断点续传，不会静默执行远程文件。
- 优先选择与当前版本精确匹配的文件级增量安装包；补丁不存在、校验失败或下载失败时回退完整安装包。
- 安装前必须匹配 Release 的 SHA-256；非法下载源、异常大小和损坏内容均会拒绝。安装器负责关闭应用并替换被占用文件，设置会先保存。
- 升级后的检查会删除旧版本安装包，保留当前版本下载用于重试；「应用临时文件」清理也纳入更新缓存。

## 跨电脑与区域兼容

- 集中管理默认下载和截图目录；Windows 视频/图片特殊目录不可用时，回退到用户目录，再回退到应用数据目录，避免误用程序安装目录。
- 页码、评分、Java 版本、播放时间、收藏查询和设置持久化使用固定区域格式，降低不同语言 Windows 上的数据差异。
- 搜索历史与直播频道恢复使用序号不敏感比较，避免区域文化比较带来的重复或匹配问题。

- Release 构建与封面 JPG/PNG/WebP 网络、磁盘缓存和异常日志专项。
- 更新协议：稳定版与同版本判断、增量优先、完整包回退、断点续传、缓存复用、SHA-256 损坏拒绝及非官方地址拒绝。
- 更新桌面回归：自动弹窗、更新说明、设置入口、手动检查、关闭自动检查及重启保持。
- 窗口、布局、关闭、推荐、媒体库和投屏回归通过。
- 独立 AppId 的完整安装及 1.8.0→1.8.1 增量升级均核对 957 个文件哈希；用户数据、自定义文件和原卸载记录保留，卸载清理通过。
- 真实执行“更新弹窗 → 增量下载 → SHA-256 → 干净退出 → 安装 → 自动重启”端到端链路通过。
