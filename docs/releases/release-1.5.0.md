# 流光影院 1.5.0

本版本完成阶段 1 核心体验与稳定性升级：重构弹幕渲染引擎并完善弹幕设置，深度优化播放器功能与单播放器模式内存占用，全面改造网盘流式预读代理以消除卡顿，修复玩偶哥哥站点频繁 403 问题，并新增内置站点验证码与安全验证鉴权流。

## 弹幕渲染与设置

- 新增 VSync 驱动的 `DanmakuOverlay`（`CompositionTarget.Rendering` + `TranslateTransform` 零布局重排 + 元素对象池 + 播放时钟高精度插值），彻底解决原先 500ms 快照跳变与 `Canvas.SetLeft` 导致的弹幕滚动卡顿。
- 支持滚动、顶部、底部三种弹幕模式及防重叠智能轨道调度，兼容 XML/JSON 弹幕模式字段。
- 完善弹幕设置面板（右键点击底部弹幕按钮或通过播放选项进入），支持实时预览调节：不透明度、字号、滚动速度、显示区域（1/4 屏至全屏）、同屏密度、颜色模式、文字描边阴影与粗体、类型过滤（滚动/顶部/底部/彩色）、时间轴偏移（±15 秒）、加载本地弹幕（`.xml`/`.json`）以及一键恢复默认样式。

## 播放器功能与单播放器模式内存优化

- 消除 LibVLC 启动阶段的重复初始化（改为直接随 `VideoView` 交换链单次初始化），单播放器直达模式冷启动至首帧挂载缩短至约 0.7 秒。
- 单播放器（`PlayerOnly`）模式延迟初始化 HTTP/DNS/B 站/在线媒体服务，移除侧栏导航树、Mica 背景与系统托盘资源，并按硬解/软解限制 `avcodec-threads` 与本地缓存，显著降低内存占用。
- 新增画面比例/裁剪模式（默认、16:9、4:3、21:9、填充裁剪，快捷键 `A`）、字幕与音频延迟微调、单集循环、视频截图、媒体信息 HUD（快捷键 `I`）、逐帧步进（`.`）、滚轮调音量、快捷操作 OSD 提示及更完整的快捷键支持（`D`/`J`/`L`/`[`/`]`/`N`）。
- 播放快照刷新提速至 250ms，拖动/快进即时响应；本地视频跳过网络卡顿预缓存停顿逻辑。

## 网盘在线播放流畅度优化

- 新增 `CloudBlockCache` 共享渐进式分块缓存：同一媒体会话下的多次 Range 连接与拖动（含 MP4 `moov` 探测与回跳）共享有界内存块缓存，数据到达即流式吐出，无需等待整块下载完成。
- 缓存 302 CDN 重定向目标地址，避免每次 Range 请求与拖动重复经历重定向；修复无扩展名网盘直链未启用预读的盲区；用 15 秒空闲超时替代固定总耗时超时，避免弱网/限速网盘下载被中途误杀。
- 新增网盘 HLS 转码流（`.m3u8`）分片前瞻预读（自动后台预读后续 2 个分片），消除夸克/UC 高清转码流切片停顿。
- 修复 `PrefetchStream` 在单线程退避时停止预读的问题；默认安全加速调整为 3 连接 × 2 MB 分块（支持 1–6 连接、1–8 MB）。

## 玩偶哥哥 403 修复与站点验证码鉴权

- `WoggNativeProvider` 优先使用健康可用镜像、增加请求超时与瞬时重试、规范完整浏览器请求头、限制单源并发并维护 403 冷却窗口，避免短超时误回落至 Cloudflare 403 主站。
- 新增 `SiteSessionStore`（基于 Windows DPAPI 加密持久化同源 Cookie 与匹配 UA，严格禁止跨域透传）和内置可见验证对话框 `SiteVerificationDialog`（支持图形验证码输入刷新与交互式 WebView 安全验证）。
- `HtmlVodProvider`（奥特影视）自动发现最新搜索入口（如 `/auete5so.php`），并在触发验证码时提供一键「验证」入口，验证完成后自动恢复搜索与访问；同样支持玩偶、B 站 `-352` 等站点的安全验证提示与恢复。

## 安装器启动优化

- 移除每次启动都将 155 MB 完整安装包二次释放到随机临时目录的 `.NET` 外壳封装，改为直接输出原生 Inno Setup 安装程序并保留目录可写性预检与 Medium 完整性校验，消除重复磁盘拷贝与二次安全扫描卡顿，启动时间由 30 秒以上缩短至约 2 秒内。
