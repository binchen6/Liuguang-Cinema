# 流光影院 2.0.3

## 界面与播放器

- 主导航和其他透明控件会在鼠标离开、捕获丢失或交互取消后收起悬停高光。设置分区复用主导航的单选样式，选中和悬停底板覆盖整个按钮。
- 音乐播放器的返回键和右侧菜单使用视频播放器同一组左右边距。宽屏上播放坞继续居中。
- 在线歌词匹配按曲名、歌手、时长和专辑核对候选。封面和歌词可独立匹配。播放器支持双语滚词、调整主语言和切换站点提供的音质。
- 音乐播放器可手动调用已配置的百炼服务生成带时间戳的滚动歌词。歌词翻译同样按需触发，可识别原词语言并选择翻译目标语言。歌词和译文可以在本机复用。
- 媒体库和视频播放器支持磁力链接。站点返回的磁力线路可直接进入正常的播放和下载流程，连接前由用户确认。播放器选择资源中体积最大的可播放音视频，支持拖动进度。
- 媒体库的观看记录、收藏、下载和本地媒体使用统一的大尺寸完整封面。观看记录支持批量删除和打开节目详情。本地视频优先读取文件自带资料及同名封面，在线补全要求片名和年份匹配。
- 恢复默认弹弹play设置时同步清除自定义凭据和中继，再实测默认连接。播放器会复用本机弹幕及已确认无匹配的记录，手动匹配可以更新记录。
- 易听通过酷狗官方网页播放器解析音频。原站未提供可播音频时，播放器显示提示并提供原站入口。
- M3U8 净化默认开启，可在「设置 → 播放」关闭。净化只移除具有完整插播标记的点播片段，直播、加密及使用独立音轨的列表保留原时间轴。

## 站点与安全

- 依赖 Android 原生库的站点可声明站方提供的 `desktopApi` 兼容接口，沿用原站目录、搜索、详情和播放。外部 Java 适配器遇到原生链接错误时会给出相应提示。
- 首次安装从空片库开始。旧版饭太硬配置会迁移到已导入仓库，并按需启用饭太硬适配包。比特采用站方公布的桌面域名，盘搜类接口支持站方配置的镜像。搜索验证会复查原请求，站点拒绝访问时会显示实际错误。
- 外部 Java 和 Python 适配器默认关闭，需要时可在「设置 → 片源」启用。客户端停止向外部适配器传递本机网盘凭据，并清理与当前凭据匹配的旧版明文副本。
- Java 适配引擎更新至 Bouncy Castle 1.87，纳入上游安全修复。
- 新增磁力元数据进程的时间、内存和结果大小限制，校验缓存文件名，关闭端口自动映射。

## 站点实测状态

- 比特的新域名已验证首页、分类、四组搜索样本和剧集详情。播放线路依赖原站网页播放器，公开实播仍待确认。
- 盘搜和易搜的原配置端点出现连接错误、超时或 HTTP 502。通用搜索、备用地址及磁力结果已通过本地协议验证。
- 粤迷、光影、花生、奶酪、风云和荐片当前缺少可用的公开桌面接口，适配包会显示对应说明。已有授权接口的仓库可通过 `desktopApi` 接入。
- 易听的榜单与歌曲页可打开。抽查的酷狗歌曲页未提供可播放音频，客户端会显示相应提示。
