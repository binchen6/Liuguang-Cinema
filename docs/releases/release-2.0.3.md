# 流光影院 2.0.3

## 界面与播放器

- 主导航和其他透明控件会在鼠标离开、捕获丢失或交互取消后收起悬停高光。设置分区复用主导航的单选样式，选中和悬停底板覆盖整个按钮。
- 音乐播放器的返回键和右侧菜单使用视频播放器同一组左右边距。宽屏上播放坞继续居中。
- 在线歌词匹配按曲名、歌手、时长和专辑核对候选。封面和歌词可独立匹配。播放器支持双语滚词、调整主语言和切换站点提供的音质。
- 音乐播放器复用已配置的百炼服务生成带时间戳的滚动歌词，并支持自动识别原词语言和选择翻译目标语言。歌词和译文可以在本机复用。
- 媒体库和视频播放器新增「打开磁力链接」。确认连接后，播放器选择资源中体积最大的可播放音视频，支持拖动进度。结束会话后断开节点并清理缓存。
- 易听通过酷狗官方网页播放器解析音频。原站未提供可播音频时，播放器显示提示并提供原站入口。
- M3U8 净化默认开启，可在「设置 → 播放」关闭。净化只移除具有完整插播标记的点播片段，直播、加密及使用独立音轨的列表保留原时间轴。

## 站点与安全

- 依赖 Android 原生库的站点可声明站方提供的 `desktopApi` 兼容接口，沿用原站目录、搜索、详情和播放。外部 Java 适配器遇到原生链接错误时会给出相应提示。
- 外部 Java 和 Python 适配器默认关闭，需要时可在「设置 → 片源」启用。客户端停止向外部适配器传递本机网盘凭据，并清理与当前凭据匹配的旧版明文副本。
- Java 适配引擎更新至 Bouncy Castle 1.87，纳入上游安全修复。
- 新增磁力元数据进程的时间、内存和结果大小限制，校验缓存文件名，关闭端口自动映射。
