# 流光影院 1.2.0 变更说明

日期：2026-11-20
基线：1.1.9 → 1.2.0
本版本主题：**前端视觉与体验重构**（字号/控件/封面整体放大一档，建立「深墨底 + 暖金流光」新视觉语言），并顺带修复启动与缓存策略。

## 2026-11-21 安装与稳定性修订

- 安装包在普通 Windows 目录生成，打包脚本核对发布目录及 EXE 的完整性标记。原安装路径已完成 1.1.8 到 1.2.0 的静默覆盖，验证卸载记录、开始菜单快捷方式、965 个文件哈希和用户数据库。
- 打包保留临时目录回退。现用安装目录拒绝写入时，安装器在替换文件前报告 Windows 错误码。
- 下载遇到不完整的 HTTP 206 时保留已有文件。比特的单页分类到达末页后结束加载，奥特仍可按原站翻页。[开发指南](../development.md) · [后台调试证据](../archive/site-verification-history.md) · 发布包校验记录（历史本地验收）

## 一、视觉与布局

- 新增设计令牌体系 `src/TV/Styles/Tokens.xaml`：语义色（深色/浅色/高对比度）、字阶（页面标题 30/38、分区 21/28、卡片标题 16/22、正文 15/22、次级 14/20、元数据 13/18）、4px 间距网格、圆角六档（4/8/10/12/16/999）、控件尺寸（导航项 48、主按钮 44、次按钮 40、输入 44、列表行 48）。
- 新增控件样式库 `src/TV/Styles/Controls.xaml`：主/次/幽灵/图标按钮、筛选胶囊、导航项、面板卡片、输入框与下拉，并覆盖 WinUI 默认主题资源，使内置控件跟随暖金强调色。
- 应用壳重做（`MainWindow.xaml`）：全高侧栏（品牌 + 点播/直播/媒体库/投屏 + 底部设置）、图标与文字标签、当前项暖金底+左侧指示条；窄窗（<920 DIP）自动收敛为 76 宽紧凑栏；标题栏仅保留品牌与返回键；页面切换/全屏/画中画/托盘行为保持。
- 八个页面全部重构：点播（精选横滑 + 分类胶囊 + 吸顶筛选 + 海报网格 + 回到顶部）、搜索（逐站进度/历史/筛选，不自动搜）、详情（信息—主操作—来源线路—选集—相关）、播放器（顶部信息栏 + 底部分组控制条 + 自动隐藏）、直播（源—分组—频道—播放三栏，窄窗单任务）、投屏（接收状态 + 设备会话 + 接收舞台）、媒体库（继续观看/收藏/下载三面板 + 空态）、设置（左侧 7 分区导航：片源/播放/网盘/网络/外观与内容/存储/关于）。
- 统一圆角规范（本次按用户反馈修正）：文字徽标 4、按钮/输入 8、筛选与分段 10、卡片/海报 12、面板/弹层 16，纯圆仅用于图标圆钮；同屏不超过 3 档。
- 其他视觉修复：删除标题栏重复搜索控件（保留点播页页头「打开搜索」与 Ctrl+F）；搜索页列头与列表对齐；直播页去掉重复下拉、分组为空隐藏标题；侧栏选中态重复高亮修复；海报封面横竖自适应（竖版填满、横版完整显示）。

## 二、行为与数据

- 配置刷新策略：命中本地配置缓存时**立即出内容**，仅在每天 6/12/18 点时段或内容过期时后台刷新（`SourceConfigService.IsRefreshDueAsync`）；`设置 → 片源 → 自动刷新接口` 仍可关闭。
- 首页内容缓存：站点首页写入 SQLite 元数据缓存（12h），启动优先用缓存（二次启动约 1 秒出内容）；站点取数失败时按「其它可用站点 → 豆瓣推荐 → 本地缓存」顺序兜底，不再每次启动都回退豆瓣。
- 首页启动请求超时由 5s 调整为 12s（慢站点如比特首页 >10s 不再被误判失败）。
- 配置缓存命中路径修复（此前每次启动仍会同步拉远端）。

## 三、兼容性

- 数据目录、数据库结构、设置项键名均未变化，可直接覆盖升级 1.1.9。
- 界面控件名称 `AutomationProperties.Name`（打开搜索/搜索关键词/设置内容/导入仓库/开始接收/投屏内容 等）保持稳定，回归脚本同步了「设置」由 ListViewItem 改为 Button 的差异（select→invoke）。

## 四、已知问题（下一阶段处理）

- 首次无缓存启动最坏约 12 秒（比特首页慢）；二次启动约 1 秒。
- 搜索结果为多站并列，尚未按影片聚合去重；搜索页结果封面尚未接横竖自适应。
- 详情页选集未自动定位当前集。
- 三档分辨率与 100/125/150% DPI 全量截图尚未补齐。
- 收尾回归（exe = bin/Release/net10.0-windows10.0.19041.0/win-x64/TV.exe，TV.dll 1.2.0.0）：9 个脚本中 7 个 PASS
  （workspace_layout / window / recommendation / library / close_dialog / hdr_desktop / search）。
  待修 2 个：cast_regression（窄窗投屏页不可滚动、手机扫码不可见）、popup_regression
  （播放器「音量」按钮 UIA bounds 无效）。证据见 `artifacts/qa-1.2.0/` 与 `artifacts/tmp/*_run*.log`。
- 收尾补丁：修复投屏页静默打不开（`CastPage.xaml` 的 `Padding="{StaticResource SpaceXLarge}"` 类型错误）、
  侧栏双选中高亮（`UpdateNavVisuals` 用 code-behind 校正）、视觉对齐（各页标题/列表/分段基线 ±6 DIP）、
  播放器打开即全屏（双击不再切全屏）、搜索结果虚拟化导致脚本点击失败（脚本改为先滚动再点）、
  设置页「仓库链接」可访问名、音量滑块重复名称改 `音量滑块`。
