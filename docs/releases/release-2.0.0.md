# 流光影院 2.0.0

## 弹幕屏蔽

- 右键点播放器的弹幕开关，选择「正则表达式屏蔽」。每行写一条 .NET 正则，点击「应用并关闭」后生效。语法有误时会标出行号，原有规则继续生效。
- 普通屏蔽词继续按字面匹配。基础广告规则缩小到带有效格式的群号或联系方式的招揽语，以及整条低价代充、代刷广告。正常聊天中提到这些词时仍可显示。
- 弹幕在后台筛选，耗时过长的正则会提示并跳过。关闭弹幕时立即清除屏幕上的文字，播完时停止逐帧更新。

## 播放、片源与兼容性

- 新增仓库资源包管理、导入时自定义仓库名、已导入仓库重命名。片源适配扩展到更多 TVBox 通用协议、HTML 页面与 drpy2 脚本。
- 资源包清单从配置的来源读取，ZIP 支持通过镜像下载并校验 SHA-256。带校验值的外部 JAR 若校验不符，会提示修正片源配置。
- 修复多任务同时探测 Python 和中文路径的兼容问题。Java DEX 转译适配 JDK 17 和 21。Python 片源仍需要本机 Python 3。
- 玻璃光效在交互时按需创建，页面卸载时释放。去掉本地播放开始后强制执行的内存回收，减少首播阶段对播放的干扰。

## Windows x64 下载

- `TV-Setup-2.0.0-x64.exe` · 完整安装包。
- `TV-2.0.0-win-x64-portable.zip` · 解压即用的便携包。
- `TV-Update-2.0.0-from-1.9.7-x64.exe` · 从 1.9.7 升级的增量包。其他旧版本可用完整安装包。

每个包都附有 `.sha256` 校验文件。安装包内置 .NET、Java 和 VC++ 运行时。
