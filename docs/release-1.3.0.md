# 流光影院 1.3.0 变更说明

日期：2026-11-21
基线：1.2.0 → 1.3.0

## 网盘登录与恢复

- 阿里、夸克、UC、百度共用账号状态和登录协调器，设置页、我的云盘与播放器不会各自重复轮询。
- 百度在应用内打开官方扫码页，验证后使用 DPAPI 保存 Cookie；其他网盘保留官方二维码接口。已有凭据不回读到输入框，手动输入留空不会清空账号。
- 播放需要登录或播放中凭据过期时自动显示对应扫码面板；取消不循环，成功后恢复原站点、线路、集数、画质、轨道和进度。
- 修复反复打开/关闭扫码后取消源被重复释放的问题。

## 分享、个人云盘与画质

- 新增百度分享短链、提取码、递归目录、按账号去重转存和原画地址；玩偶与通用盘搜详情识别百度链接，未登录时保留“登录后加载分享”。
- 原生实现 `MDrive / csp_MyDriveGuard`：四网盘账号切换、目录面包屑、分页、当前账号搜索、虚拟化文件列表和个人文件直读播放。
- 阿里使用 refresh token 换取并缓存 access token；夸克/UC 复用 Cookie 轮换与账号文件接口。个人文件不再经过分享转存。
- 夸克/UC 将真实转码高度传入画质菜单；阿里/百度没有转码时只提供真实能力。
- 盘搜成功结果短期缓存并合并重复请求，盘他详情可尝试多个分享。盘她、聚剧、抠搜、优汐仍只有 Guard 配置且没有公开端点，保持明确阻塞，不伪造支持。

## 稳定与安全加速

- 代理会话可按原文件与画质刷新过期地址；初始 401/403/412 和预取后续分块 412 均从正确 Range 继续。
- 保留 Content-Range、总长度与 ETag 校验；429/5xx 退避并停止新增并行分块，上游忽略 Range 时回退原始响应。
- 活动会话有上限，停播、切集和离开播放器释放会话及 HLS 子资源；本地代理仍只监听 `127.0.0.1`。
- 播放未起播时可按设置有限尝试后续线路，不把地址解析成功冒充播放成功。

## 设置与 UI/UX

- 设置显示四网盘状态、验证、打开我的云盘、真实存储统计和来源摘要；新增默认画质、失败自动切线、危险操作确认、数据目录与诊断入口。
- 修复设置分区切换后旧按钮高亮/按下状态残留，以及进入设置后主侧栏仍高亮点播的问题。
- 详情页播放/收藏/下载/投屏统一为 112×44 DIP，窄窗 2×2；恢复上次线路、集数与进度并定位当前集。
- 播放器底部控制统一 44 DIP 高、8 DIP 圆角，文字与图标按钮使用同一视觉层级，播放控制与媒体控制分组，播放键使用暖金强调。
- 搜索横版封面与媒体库缩略图接入 AutoFit；直播补台标并移除重复状态；投屏窄窗可滚动且二维码链接/复制按钮保持可见。
- 全站审查按钮尺寸、文本字阶、间距与对齐；轻点外部关闭 Flyout 的系统行为保持不变。
