本文约定「流光影院」当前实现的 UI/UX 工程边界、响应式布局、交互状态、无障碍要求与 UIA 自动化名称。

## 1. 令牌复用、统一导航与滚轮契约

- `Styles/Tokens.xaml`、`Styles/Icons.xaml`、`Styles/Controls.xaml`、`Styles/Navigation.xaml` 与 `App.xaml` 是全站样式的唯一入口；新增或修改页面必须复用既有语义资源键，禁止硬编码色值、字号或零散图标。
- **统一单选导航与杜绝选中残留**：所有横向与竖向单选导航必须使用 `SelectionMode="Single"` 的 `ListView` + `Styles/Navigation.xaml` 统一视觉状态模板 + `Controls/NavigationMotion.cs`（严禁使用 `ItemsControl + ToggleButton(OneWay)`），保证物理上不可能出现多选态残留；非虚拟化横向项模型需重写 `ToString()` 返回可读名称。
- **层级与盒子分块合理性**：每屏同时可见的真实 `AcrylicBrush` 宏观层严格控制在 `≤ 4` 块（侧栏、命令条/筛选坞、主检视台）；次级表单分组（如设置页多张卡片）采用零额外模糊的轻透建筑表面 `SettingsCardBackgroundBrush`，兼顾层次主次与 120Hz 滚动帧率；空闲状态条与加载进度条内嵌于父级栏位或按需显隐，严禁在 `Grid RowSpacing` 中留下幽灵空带；所有可滚动列表为右侧滚动条预留 `8–12 DIP` 避让内边距。
- **全站滚轮一致性（`Controls/ScrollWheelBehavior.cs`）**：
  - 独立横向条（云盘账号卡/面包屑、媒体库分段槽/监视目录）启用 `HorizontalWheelMode="Direct"`，普通滚轮与 `Shift+滚轮` 均可平滑横滑；
  - 嵌套于纵滑页的横向条（点播画廊/分类栏、详情页相关推荐）启用 `HorizontalWheelMode="ShiftOnly"`，普通滚轮 1:1 穿透纵滑不卡死、`Shift+滚轮` 顺滑横滑；
  - 详情页选集网格启用 `IsVerticalScrollChainingEnabled="True"`，滑到边界自动把滚轮交还整页；
  - 设置页 `SettingsScroller` 启用 `GuardNumberBoxWheel="True"`，滚轮经过未聚焦的 `NumberBox` 时继续滚动页面而不误改数值。
- 每个区域只突出一个墨白高反差主操作（`AccentFillBrush` / `AccentInkBrush`）；次操作使用磨砂表面、`1px` 极细描边或纯文字按钮。
- 列表与海报网格必须使用虚拟化；翻页采用增量追加，筛选与搜索禁止无意义的整页重建。

## 2. 响应式布局契约

- **主侧栏**：宽窗按文字测量在 `196–320 DIP` 间自适应（默认 `208 DIP`），包含「光隙」品牌区、键帽式全局搜索（`Ctrl+F`）、带编号的一级导航（点播、直播、媒体库、云盘、投屏）与底部设置；窄窗折叠为 `76 DIP` 图标导轨；进入播放页时隐藏。
- **点播页**：画册报头 + 宽幅展厅画廊 + GPU 驱动的 1:1 可打断收起吸顶磨砂筛选坞 + 2:3 海报网格（默认窗口海报宽 `≥188 DIP`）+ 悬浮回顶圆镜按钮。
- **详情页**：全出血磨砂画报（支持滚动视差）+ 四个统一尺寸操作按钮（空间不足转为 2×2）+ 非对称磨砂双栏工作台（片源线路与编号选集矩阵）；窄窗纵向排列。
- **搜索页**：一体化磨砂命令搜索条（内嵌 2px 朱砂进度线）+ 页面内非抢焦真磨砂建议浮层（`0ms` 本地历史/片库/前缀缓存即时上屏 + `80ms` 防抖流式并发竞速豆瓣联想与健康站点，不等待最慢源，不打断中文 IME 组合输入与粘贴）+ `244 DIP` 左侧一体化磨砂站点遥测面板 + 右侧基线对齐的历史/结果画框流。
- **直播页**：宽窗为三栏（磨砂源组导轨 + 开放频道流 + 磨砂 EPG/线路检视面板），窄窗按「直播源/分组 → 频道 → 详情」分步导航。
- **媒体库页**：磨砂分段滑轨（支持横向滚动与弹性胶囊指示器）；窄窗将搜索框独立成行；继续观看采用自适应宽幅影院卡，其余分区为高密度 Hairline 列表。
- **云盘 / 投屏 / 设置页**：宽窗充分利用画布并约束长文最大可读宽度（`800–840 DIP`）；云盘文件表与账号卡支持窄窗自适应；投屏为左遥测台 + 右同心光环舞台；设置保留 8 分区弹簧导航（片源、播放、弹幕与 AI、网盘、网络、外观与内容、存储、关于）。

## 3. 播放器与弹层契约

- **播放画面与五层光学玻璃控制层**：画面区域保持纯粹深黑；顶部双分体浮岛与修身底部悬浮控制坞均基于 `GlassSurface` 五层光学磨砂玻璃构建（柔和低遮挡真磨砂 + 体积厚度光影 + 顶部 1px 焦散高光丝 + 菲涅尔定向外框 + 克制 `ThemeShadow`）。播放中无操作 **3 秒且鼠标指针不在任何播放控件上停留**后，控制层平滑沉降并折叠（实现静默播放期 0% 模糊开销），同时通过 WinUI 3 官方 `IInputCursorStaticsInterop` 生成内存透明 `InputCursor` 绑定至播放页、`VideoView` 与 `SwapChainPanel` 的 `ProtectedCursor`（辅以静止光标刷新与物理像素防抖、全屏/缩放几何边界自愈）稳定隐藏鼠标指针；任意有效指针移动（`≥ 3px`）、悬停、暂停或离窗即刻唤醒并恢复指针，不污染全局 `ShowCursor` 计数。
- **播放防休眠与防息屏**：默认开启播放时防止电脑息屏与系统休眠（基于内核 `PowerCreateRequest` / `PowerSetRequest` Display+System 电源可用性请求，支持播放器与投屏双源引用计数）；暂停、停止、离开页面或退出应用立即释放；支持在「设置 → 播放」与播放器「更多选项」随时切换。
- **显隐锁定**：鼠标悬停于任一控件表面、拖拽进度条，或菜单、字幕/弹幕设置、登录、换源及其他对话框打开期间锁定控制层，禁止自动隐藏。
- **零延迟反馈**：播放/暂停采用乐观 UI 同步与高优原生命令队列；进度条拖动支持实时预览时间；音量、倍速、进度、字幕延迟等提示统一使用 `GlassSurface` 光学磨砂 OSD；保留 `Space`、方向键、`M`、`F`、`P`、`D`、`Z/X`、`A`、`I`、`Esc` 全部快捷键。
- **弹层与确认**：更新、登录、下载、二维码等弹层自适应窗口高度，非模态浮层支持轻点外部与 `Esc` 关闭；高风险清理、删除与退出账号必须二次确认；长耗时任务提供即时取消入口。

## 4. 无障碍、动效与防竞态

- 所有图标按钮提供 `AutomationProperties.Name` 与 `ToolTip`；主要命中区域 `≥40×40 DIP`；选中态同时通过位置指示条、底板材质与字重/色彩表达，不依赖单一颜色。
- 完整支持键盘导航：`Tab` 可达全部交互、`Enter/Space` 激活、`Esc` 逐层返回或关闭浮层。
- 所有核心转场与微交互均在 GPU Compositor 线程由 `MotionService` 驱动，支持任意时刻打断并继承动量；当 `MotionService.CanAnimate == false` 时完全禁用动画并瞬时落位。
- 快速连续点击或切页时，所有异步请求与动画回调均受令牌/版本守卫，过期结果绝不回写新状态；所有 `ListViewItem` / `ToggleButton` 视觉状态分组必须正确复位，杜绝历史选中态残留。

## 5. UIA 自动化名称契约

现有桌面回归依赖以下 `AutomationProperties.Name`，页面重构与迭代必须保持稳定（变更时须同步更新回归脚本）：

`点播`、`点播分类`、`直播`、`媒体库`、`云盘`、`投屏`、`设置`、`打开搜索`、`重新加载`、`筛选`、`站点`、`点播海报`、`回到顶部`、`搜索关键词`、`搜索建议`、`搜索`、`下载`、`收藏`、`返回`、`网盘`、`等待扫码`、`关闭扫码`、`开始接收`、`投屏内容`、`设置内容`、`导入仓库`。

> 页面布局使用 DIP，UIA 边界与截图为物理像素；跨设备对比时须记录 Windows DPI 缩放比例。
