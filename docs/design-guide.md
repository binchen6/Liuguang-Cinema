# 设计契约

本文约定「流光影院」当前实现的 UI/UX 工程边界、响应式布局、交互状态、无障碍要求与 UIA 自动化名称。

- 色彩、磨砂玻璃材质、字阶、圆角与图标令牌见 [品牌设计语言规范（SHIRO · MA · GLASS）](brand-design-system.md)。
- GPU Compositor 弹簧参数与全链路动效编排见 [动效工程规范](motion-spec.md)。
- 历史 1.2 视觉基线见 [归档](archive/design-guide-1.2.md)，仅作追溯。

## 1. 令牌复用与信息层级

- `Styles/Tokens.xaml`、`Styles/Icons.xaml`、`Styles/Controls.xaml` 与 `App.xaml` 是全站样式的唯一入口；新增或修改页面必须复用既有语义资源键，禁止硬编码色值、字号或零散图标。
- 每个区域只突出一个墨白高反差主操作（`AccentFillBrush` / `AccentInkBrush`）；次操作使用磨砂表面、`1px` 极细描边或纯文字按钮。
- 以留白与 `1px` `DividerBrush` 表达结构，克制嵌套卡片；仅在侧栏导轨、吸顶坞、浮层、检视工作台与独立任务区使用磨砂面板。
- 加载、空态、失败与成功状态明确区分：成功不显示为警示，失败保留可重试或可验证入口，空态展示清晰的几何徽章与引导操作。
- 列表与海报网格必须使用虚拟化；翻页采用增量追加，筛选与搜索禁止无意义的整页重建。
- 长文本优先换行或省略，不挤走关键按钮；列表与窄轨为右侧滚动条预留避让内边距；海报加载失败回退至建筑线框占位图标。

## 2. 响应式布局契约

- **主侧栏**：宽窗按文字测量在 `196–320 DIP` 间自适应（默认 `208 DIP`），包含「光隙」品牌区、键帽式全局搜索（`Ctrl+F`）、带编号的一级导航（点播、直播、媒体库、云盘、投屏）与底部设置；窄窗折叠为 `76 DIP` 图标导轨；进入播放页时隐藏。
- **点播页**：画册报头 + 宽幅展厅画廊 + GPU 驱动的 1:1 可打断收起吸顶磨砂筛选坞 + 2:3 海报网格（默认窗口海报宽 `≥188 DIP`）+ 悬浮回顶圆镜按钮。
- **详情页**：全出血磨砂画报（支持滚动视差）+ 四个统一尺寸操作按钮（空间不足转为 2×2）+ 非对称磨砂双栏工作台（片源线路与编号选集矩阵）；窄窗纵向排列。
- **搜索页**：一体化磨砂命令搜索条 + 页面内非抢焦真磨砂建议浮层（不打断中文 IME 组合输入）+ `244 DIP` 左侧磨砂站点遥测轨 + 右侧历史/结果画框流。
- **直播页**：宽窗为三栏（磨砂源组导轨 + 开放频道流 + 磨砂 EPG/线路检视面板），窄窗按「直播源/分组 → 频道 → 详情」分步导航。
- **媒体库页**：磨砂分段滑轨（支持横向滚动与弹性胶囊指示器）；窄窗将搜索框独立成行；继续观看采用自适应宽幅影院卡，其余分区为高密度 Hairline 列表。
- **云盘 / 投屏 / 设置页**：宽窗充分利用画布并约束长文最大可读宽度（`800–840 DIP`）；云盘文件表与账号卡支持窄窗自适应；投屏为左遥测台 + 右同心光环舞台；设置保留 8 分区弹簧导航（片源、播放、弹幕与 AI、网盘、网络、外观与内容、存储、关于）。

## 3. 播放器与弹层契约

- **播放画面与控制层**：画面区域保持纯粹深黑；顶栏与悬浮烟熏磨砂底部控制坞属于同一显隐层级，播放中无操作 5 秒后一起平滑沉降并隐藏鼠标，任意指针/键鼠交互立即反向唤醒。
- **显隐锁定**：菜单、字幕/弹幕设置、登录、换源或其他对话框打开期间锁定控制层，禁止自动隐藏。
- **零延迟反馈**：播放/暂停采用乐观 UI 同步与高优原生命令队列；进度条拖动支持实时预览时间；音量、倍速、进度、字幕延迟等提示统一使用烟熏磨砂 OSD；保留 `Space`、方向键、`M`、`F`、`P`、`D`、`Z/X`、`A`、`I`、`Esc` 全部快捷键。
- **弹层与确认**：更新、登录、下载、二维码等弹层自适应窗口高度，非模态浮层支持轻点外部与 `Esc` 关闭；高风险清理、删除与退出账号必须二次确认；长耗时任务提供即时取消入口。

## 4. 无障碍、动效与防竞态

- 所有图标按钮提供 `AutomationProperties.Name` 与 `ToolTip`；主要命中区域 `≥40×40 DIP`；选中态同时通过位置指示条、底板材质与字重/色彩表达，不依赖单一颜色。
- 完整支持键盘导航：`Tab` 可达全部交互、`Enter/Space` 激活、`Esc` 逐层返回或关闭浮层。
- 所有核心转场与微交互均在 GPU Compositor 线程由 `MotionService` 驱动，支持任意时刻打断并继承动量；当 `MotionService.CanAnimate == false` 时完全禁用动画并瞬时落位。
- 快速连续点击或切页时，所有异步请求与动画回调均受令牌/版本守卫，过期结果绝不回写新状态；所有 `ListViewItem` / `ToggleButton` 视觉状态分组必须正确复位，杜绝历史选中态残留。

## 5. UIA 自动化名称契约

现有桌面回归依赖以下 `AutomationProperties.Name`，页面重构与迭代必须保持稳定（变更时须同步更新回归脚本）：

`点播`、`直播`、`媒体库`、`云盘`、`投屏`、`设置`、`打开搜索`、`重新加载`、`筛选`、`站点`、`点播海报`、`回到顶部`、`搜索关键词`、`搜索`、`下载`、`收藏`、`返回`、`网盘`、`等待扫码`、`关闭扫码`、`开始接收`、`投屏内容`、`设置内容`、`导入仓库`。

> 页面布局使用 DIP，UIA 边界与截图为物理像素；跨设备对比时须记录 Windows DPI 缩放比例。
