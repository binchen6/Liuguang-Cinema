# 设计契约

本文描述「流光影院」当前实现的 UI/UX、品牌语言、磨砂玻璃材质、动效与自动化约定。

- 完整品牌设计语言与色彩/图标规范见 [品牌设计语言规范（SHIRO · MA · GLASS）](brand-design-system.md)。
- 完整物理动效引擎与交互编排规范见 [动效工程规范](motion-spec.md)。
- 历史 1.2 规范见[归档](archive/design-guide-1.2.md)，仅作追溯。

## 设计来源与品牌语言

`src/TV/Styles/Tokens.xaml` 管理语义颜色、磨砂玻璃画刷、字阶、间距、尺寸和圆角；`src/TV/Styles/Icons.xaml` 管理全站 24×24 统一线宽几何图标；`src/TV/Styles/Controls.xaml` 管理共用控件模板与状态。新增或修改页面必须优先复用资源键，不在页面内复制硬编码色值或尺寸。

- **品牌风格**：参考原研哉（Kenya Hara）的「白（Shiro）与余白（Ma）」哲学，融合国际现代平面设计排版秩序与建筑级磨砂玻璃（`AcrylicBrush` + `1px` 极细高光描边）。
- **双主题与高对比**：
  - **暗室素墨（Dark，默认）**：`#0B0B0D` 素墨底 + 烟熏磨砂玻璃分层 + 宣纸白（`#F4F3EE`）高反差主操作 + 朱砂红（`#E8503E`）落款强调。
  - **素白画廊（Light）**：`#F6F5F0` 宣纸白底 + 和纸透光磨砂分层 + 松烟墨（`#141416`）高反差主操作 + 印泥朱砂（`#CE3A2B`）落款强调。
  - **高对比度（HighContrast）**：全部画刷自动映射到系统高对比语义色。
- **品牌标识**：采用「光隙 · Aperture」几何徽标，配备 9 档尺寸 `App.ico`（16–256）与应用内纯矢量 XAML 标识。
- **字阶**：大片名 34、页面主标题 30、分区标题 20、卡片标题 16、正文 15、辅助文字 14、元数据与索引眉 13 DIP；全站无 11px 以下可读文本。
- **控件**：导航项 48 高，主按钮 44 高，次按钮和图标按钮 40 高，输入框 44 高；主要命中区域不小于 40×40。
- **间距与圆角**：使用 4 DIP 网格（常用 8、12、16、24、32）；圆角为标签 4、控件 8、海报卡片 10、磨砂面板 14、胶囊 18、圆形 999。

## 信息层级与状态

- 每个区域只突出一个墨白高反差主操作；次操作使用磨砂表面色、1px 极细描边或纯文字样式。
- 以留白与 `1px` Hairline 分割线表达结构，克制使用卡片，仅在浮层、导轨、检验工作台与独立任务区使用磨砂面板。
- 加载、空内容、失败和成功是明确区分的状态；成功操作不显示为警告，失败保留可重试或可验证入口。
- 长文本优先换行或省略，不挤走关键按钮；弹层内容过高时内部滚动。
- 列表和网格使用虚拟化，筛选与搜索避免无意义的整页重建。
- 海报失败显示几何占位图标；详情元数据可换行，评分、年份、地区、来源不依赖横向超宽容器。

## 响应式布局

- **主侧栏**：磨砂透光导轨；宽窗按文字测量在 196–320 DIP 间自适应，包含「光隙」品牌区、键帽式全局快捷搜索（`Ctrl+F`）、带画册索引的一级导航（点播、直播、媒体库、云盘、投屏）及底部设置；窄窗折叠为 76 DIP 图标导轨，播放页隐藏。
- **点播页**：画册报头 + 展厅宽幅磨砂铭牌画廊 + 滚动自动切换的吸顶磨砂筛选坞 + 画框质感海报网格（默认窗口海报宽 ≥188 DIP）与悬浮磨砂「回到顶部」圆镜按钮。
- **详情页**：全出血环境柔光磨砂画报区（支持滚动视差）+ 四个统一尺寸主次操作（空间不足转为 2×2）+ 非对称磨砂双栏工作台（片源线路与编号选集矩阵）；窄窗依次纵向排列。
- **搜索页**：一体化磨砂命令搜索条 + 真磨砂非抢焦建议浮层 + 左侧磨砂站点遥测轨 + 右侧历史/结果画框流。
- **媒体库页**：磨砂分段滑轨（带弹性胶囊指示器）支持横向滚动；窄窗将搜索框独立成行；继续观看为宽幅影院卡，其余分区为高密度 Hairline 列表。
- **直播页**：带朱砂 ON AIR 呼吸灯的广播控制台；宽窗为三栏（磨砂源组导轨 + 开放频道流 + 磨砂详情面板），窄窗按「直播源/分组 → 频道 → 详情」分步导航。
- **云盘 / 投屏 / 设置页**：宽窗充分利用内容区并约束正文最大可读宽度；投屏保留左侧遥测控制台与右侧同心光环舞台；设置保留带弹簧滑轨指示条的 8 分区导航（片源、播放、弹幕与 AI、网盘、网络、外观与内容、存储、关于）。

## 播放器

- 画面区域保持纯粹深黑；顶部栏、悬浮式烟熏磨砂玻璃底部控制坞属于同一显隐层级，播放中无操作 5 秒后平滑沉降并隐藏鼠标，任意交互即时反向唤醒。
- 菜单、登录、换源或其他对话框打开时锁定控制层，不自动隐藏。
- 播放/暂停主按钮采用高反差墨白圆角徽章，进度条使用朱砂光束与等宽数字时间码；OSD、AI 进度条、实时字幕与媒体 HUD 统一使用烟熏磨砂玻璃胶囊。
- 加载、缓冲、错误、直播和结束状态有明确可操作反馈；保留 Space、方向键、M、F、P、D、Z/X、A、I、Esc 等全部快捷键。

## 设置与弹层

- 高风险清理、删除和退出账号需要明确确认；普通设置即时反馈并异步保存。
- 二维码、下载、更新、登录与播放设置弹层自适应窗口高度，统一采用磨砂表面与 Hairline 层次；更新弹窗清晰展示版本、更新内容、包类型与进度。
- 轻点弹层外部可关闭非模态浮层；长耗时任务提供即时取消入口。

## 无障碍与物理动效

- 所有图标按钮提供 `AutomationProperties.Name` 和工具提示；选中态同时通过位置指示条、底板材质与字重/颜色共同表达。
- Tab 可达全部操作，Enter/Space 激活，Esc 关闭当前浮层或返回。
- 所有核心转场、悬停、按压、滑轨指示条与播放器控制层均由 `MotionService` 在 Compositor 线程驱动，支持中途任意打断并继承物理动量；`MotionService.CanAnimate` 为 false 时完全禁用动画并瞬时落位。
- 快速连续操作时，旧动画回调或旧异步任务绝不回写新状态。

## 自动化契约

现有回归依赖以下 UIA 名称，重构与后续迭代必须保持稳定（若变更需同步更新回归脚本）：
`点播`、`直播`、`媒体库`、`云盘`、`投屏`、`设置`、`打开搜索`、`重新加载`、`筛选`、`站点`、`点播海报`、`回到顶部`、`搜索关键词`、`搜索`、`下载`、`收藏`、`返回`、`网盘`、`等待扫码`、`关闭扫码`、`开始接收`、`投屏内容`、`设置内容`、`导入仓库`。

页面尺寸使用 DIP，UIA 截图和边界通常为物理像素；比较时应记录 Windows 缩放比例。
