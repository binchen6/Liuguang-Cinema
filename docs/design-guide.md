# 设计契约

本文描述当前实现的共同 UI/UX 约定。历史 1.2 规范见[归档](archive/design-guide-1.2.md)，不再作为当前操作指南。

## 设计来源

`src/TV/Styles/Tokens.xaml` 管理颜色、字阶、间距、尺寸和圆角，`Styles/Controls.xaml` 管理共用控件状态。新增页面优先复用资源键，不在多个页面复制相同尺寸或颜色。

- 视觉：深墨底、暖金强调，支持浅色和系统高对比主题。
- 字阶：页面标题 30、分区标题 21、卡片标题 16、正文 15、辅助文字 14、元数据 13 DIP。
- 控件：主按钮 44 高，次按钮和图标按钮 40 高，导航项 48 高；主要命中区域不小于 40×40。
- 间距：使用 4 DIP 网格，常用间距为 8、12、16、24、32。
- 圆角：标签 4、控件 8、胶囊 10、卡片 12、面板 16。

## 信息层级与状态

- 每个区域只突出一个主操作；次操作使用表面色、描边或纯文字样式。
- 加载、空内容、失败和成功是不同状态。成功操作不能显示为警告，失败应保留可重试入口。
- 长文本优先换行或省略，不能挤走关键按钮；弹层内容过高时内部滚动。
- 列表和网格使用虚拟化，筛选与搜索避免无意义的整页重建。
- 海报失败显示占位图标；详情元数据可换行，评分、年份、地区、来源不依赖横向超宽容器。

## 响应式布局

- 主侧栏宽窗按文字测量，在 196–320 DIP 间调整；窄窗使用 76 DIP 图标栏，播放页隐藏。
- 详情页四个主操作统一 112×44 DIP，空间不足时变为 2×2；封面、信息和来源/选集在窄窗依次纵向排列。
- 媒体库页头在窄窗将搜索框独立为一行；分段标签允许横向滚动。
- 直播宽窗为三栏，窄窗按“直播源/分组 → 频道 → 详情”分步导航。
- 投屏和设置在宽窗利用内容区，窄窗保证主要操作可见且可滚动。

## 播放器

- 顶部标题、进度条和底部控制属于同一显隐层级，播放中无操作 5 秒后一起隐藏，同时隐藏鼠标。
- 菜单、登录、换源或其他对话框打开时保持控制层，不在用户选择过程中自动隐藏。
- 播放键使用暖金填充，其余操作使用透明或轻量底色；不为每组按钮叠加重厚卡片。
- 加载、缓冲、错误、直播和结束状态应有明确反馈，不能仅显示永久进度环。
- 保留 Space、方向键、M、F、P、D、Z/X（字幕前移/后移）、A、I、Esc 等快捷键；拖动进度时不让后台快照覆盖用户预览值。

## 设置与弹层

- 设置按片源、播放、弹幕与 AI、网盘、网络、外观与内容、存储、关于分区导航。
- 高风险清理、删除和退出账号需要确认；普通设置即时反馈并异步保存。
- 二维码、下载和播放设置弹层应适应窗口高度，主要操作与危险操作分离。
- 轻点弹层外部可关闭非模态浮层；正在处理的重要任务需提供明确取消方式。

## 无障碍与动效

- 所有图标按钮提供 `AutomationProperties.Name` 和工具提示，文字颜色不是选中状态的唯一线索。
- Tab 可到达全部操作，Enter/Space 激活，Esc 关闭当前浮层或返回。
- 微交互通常为 100–180ms；`MotionService.CanAnimate` 为 false 时禁用动画。
- 快速连续操作时，旧动画或旧异步任务不能回写新状态。

## 自动化契约

现有回归依赖以下名称，修改前应同步更新测试并确认替代名称稳定：`点播`、`直播`、`媒体库`、`投屏`、`设置`、`打开搜索`、`重新加载`、`筛选`、`站点`、`点播海报`、`回到顶部`、`搜索关键词`、`下载`、`收藏`、`返回`、`网盘`、`等待扫码`、`关闭扫码`、`开始接收`、`投屏内容`、`设置内容`、`导入仓库`。

页面尺寸使用 DIP，UIA 截图和边界通常为物理像素；比较时应记录 Windows 缩放比例。
