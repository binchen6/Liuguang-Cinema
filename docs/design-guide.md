# 设计契约

本文约定「流光影院」当前 UI/UX 工程边界、响应式布局、交互状态、无障碍要求与 UIA 自动化名称。

- 色彩、光学玻璃表面与 `GlassOpticsEngine` 规范见 [视觉与材质规范](brand-design-system.md)。
- Compositor 弹簧参数与动效编排见 [动效工程规范](motion-spec.md)。

---

## 1. 样式复用、光学玻璃与滚轮契约

- `Styles/Tokens.xaml`、`Styles/Icons.xaml`、`Styles/Controls.xaml`、`Styles/Navigation.xaml` 与 `App.xaml` 为全站样式入口；新增控件须复用既有语义令牌，禁止硬编码色值或零散图标。
- **统一单选导航**：横向与竖向单选导航均使用 `SelectionMode="Single"` 的 `ListView` + `Styles/Navigation.xaml` + `Controls/NavigationMotion.cs`，列表重建时由 `NavigationRailController` 自动重挂选中指示器，非虚拟化项模型须重写 `ToString()`。
- **玻璃层与光学引擎边界**：每屏宏观 `AcrylicBrush ≤ 4` 块；玻璃容器与交互按钮通过 `GlassSurface` 或 `GlassOpticsEngine.Mode="Interactive"` 接入 GPU 光学反光/折射/点击波纹；状态条内嵌于父栏位或按需折叠，可滚动列表右侧预留 `8–12 DIP` 滚动条内边距。
- **滚轮一致性（`Controls/ScrollWheelBehavior.cs`）**：
  - 独立横向条（云盘账号卡/面包屑、媒体库分段槽/监视目录）采用 `HorizontalWheelMode="Direct"`；
  - 嵌套于纵滑页的横向条（点播画廊/分类栏、详情页相关推荐）采用 `HorizontalWheelMode="ShiftOnly"`，普通滚轮驱动整页纵滑；
  - 详情页选集网格启用 `IsVerticalScrollChainingEnabled="True"`；设置页与弹层滚动区启用 `GuardNumberBoxWheel="True"` 防止滚轮误改数值。
- 列表与海报网格使用虚拟化与增量分页；每个区域仅突出一个高反差主操作。

## 2. 响应式布局契约

- **主侧栏**：宽窗在 `196–320 DIP` 间自适应（默认 `208 DIP`），挂载 `GlassOpticsEngine`（`Profile="Rail"`），窄窗折叠为 `76 DIP` 图标导轨，进入播放页隐藏。
- **点播页**：页眉 + 顶栏**多仓库切换胶囊**（展示自定义仓库名并支持跨仓隔离切换/直达导入）+ 推荐画廊 + 随滚动收起的吸顶筛选坞 + 2:3 海报网格（默认宽 `≥188 DIP`）+ 悬浮回顶按钮。
- **详情页**：顶部背景画报（支持滚动视差）+ 4 个统一尺寸操作按钮（窄窗 2×2）+ 双栏线路与选集矩阵（窄窗纵向排列）。
- **搜索页**：命令搜索条（底部内嵌 2px 进度线）+ 页面内非抢焦联想浮层（本地历史/片库即时上屏 + 80ms 防抖远端并发，不中断中文 IME）+ `244 DIP` 左侧站点遥测面板 + 右侧结果流。
- **直播页**：宽窗三栏（源组导轨 + 频道列表 + EPG/线路面板），窄窗分步导航。
- **媒体库页**：横向分段滑轨（窄窗搜索框独立成行）；**继续观看**采用响应式全宽自适应宽屏信息流网格（`HistoryGrid` + `UpdateHistoryGridLayout()`）：
  - 随 `Loaded`、`SizeChanged` 与标签切换动态计算 `1–6` 列（最小卡片宽 `264 DIP`、理想宽 `318 DIP`），单元格按可用宽度整除铺满，彻底消除右侧留白；
  - 卡片高按宽屏比例（`0.45 / 0.545 / 0.568`，钳制 `164–246 DIP`）自适应缩放，每张卡片接入 `GlassOpticsEngine`（`Profile="Card"`）；
  - 收藏、下载与本地视频保持高密度列表。
- **云盘 / 投屏 / 设置页**：约束长文最大可读宽（`800–840 DIP`）；设置在 8 分区导航（片源、播放、弹幕与 AI、网盘、网络、外观与内容、存储、关于）下，**片源**分区提供：当前仓库选择、导入弹层（含可选「自定义仓库名称」）、已导入仓库逐项「使用 / 重命名 / 移除」，以及 **仓库资源包** 管理卡片（刷新清单、实时国内加速路由与进度条、下载/更新/卸载）。

## 3. 播放器与弹层契约

- **纯黑画面与光学控制坞**：画面区保持纯黑；顶部双浮岛与底部控制坞基于 `GlassSurface` + `GlassOpticsEngine`（`Profile="Cinema"`），严禁在 `SwapChainPanel` 上叠加 `ThemeShadow`。
- **音乐播放器**：宽窗左侧封面和曲目信息，右侧为逐句歌词，窄窗纵向排列。带时间戳的歌词跟随播放时钟，当前句居中提亮，手动滚动后短暂暂停跟随。播放器控件使用清透渐变、内倒角和焦散边光。节拍光影仅使用当前应用音频，遵循系统无动画和高对比度设置。
- **入射光与玻璃**：背景主光和反射光使用不同方向、速率和散射范围，控制坞与封面从同一组光源计算入射角和亮度。玻璃边缘随掠射角增亮。交互卡片和按钮复用统一光学样式，虚拟化列表在交互前不创建合成光效。
- **低开销指针追踪与 3 秒自动隐藏**：
  - `OnPointerMoved` 采用 O(1) 节流快路径（`200ms` 物理指针位移采样，不遍历可视化树），消除高回报率鼠标移动卡顿；
  - 无操作 **3 秒且鼠标未悬停控件**后平滑收起控制层并折叠，同步通过原生透明 `InputCursor` 绑定 `ProtectedCursor` 隐藏光标；有效移动（`≥ 3px`）、触控、暂停或失焦即刻恢复（不调用 `SetCursorPos`）。
- **播放期防休眠**：默认通过 `PowerCreateRequest` / `PowerSetRequest`（Display + System 引用计数）阻止息屏与休眠，暂停/停止/离页即释放，可在设置与播放器菜单开关。
- **硬解与显隐锁定**：默认 `:avcodec-hw=any` 自动回退；悬停控件、拖拽进度条或任意弹层/对话框打开期间禁止自动隐藏。
- **弹层单滚动条与确认**：`FlyoutPresenter` 与 `ContentDialog` 禁止再嵌套外层 `ScrollViewer`；内嵌 `ListView` 的弹层通过静态样式禁用宿主滚动条；高风险清理、删除与退出账号须二次确认。

## 4. 无障碍、防竞态与 UIA 名称契约

- 所有图标按钮提供 `AutomationProperties.Name` 与 `ToolTip`，主要命中区 `≥40×40 DIP`，完整支持 `Tab` / `Enter` / `Space` / `Esc` 键盘流。
- 所有异步加载与延迟退场回调均带取消令牌与代际版本守卫，过期结果绝不回写新状态。
- 桌面回归依赖以下稳定 `AutomationProperties.Name`（变更须同步更新回归脚本）：

`点播`、`点播分类`、`直播`、`媒体库`、`云盘`、`投屏`、`设置`、`打开搜索`、`重新加载`、`筛选`、`站点`、`点播海报`、`回到顶部`、`搜索关键词`、`搜索建议`、`搜索`、`下载`、`收藏`、`返回`、`网盘`、`等待扫码`、`关闭扫码`、`开始接收`、`投屏内容`、`设置内容`、`导入仓库`。

> 布局采用 DIP，UIA 边界与截图为物理像素；跨机比对须记录 Windows DPI 缩放。
